# Ondas de Calor e Frio — WebApp

**[Ver a demo →](https://drodrigues704-coder.github.io/ondas_calor_frio_app/)**

Esta é a versão estática (sem backend) da WebApp — os dados que noutro
contexto seriam calculados em tempo real por um servidor (recorte por
região, séries temporais) foram pré-calculados e estão em `data/`. O
código-fonte completo e o processo de desenvolvimento mantêm-se num
repositório privado; ver
[ondas_calor_frio_showcase](https://github.com/drodrigues704-coder/ondas_calor_frio_showcase)
para uma apresentação do projeto (capturas de ecrã, metodologia,
contacto).

Autor: Daniel Rodrigues

## Nota sobre este repositório

Este é um instantâneo estático para demonstração — não corre o
pipeline de dados nem recalcula nada, e não inclui os dados brutos de
reanálise CERRA nem o código de processamento do backend. Todos os
direitos reservados; não é software de código aberto.
