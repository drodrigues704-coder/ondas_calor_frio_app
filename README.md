# Ondas de Calor e Frio — WebApp

Aplicação publicada via GitHub Pages: veja o link em **About** deste
repositório (aparece assim que o GitHub Pages terminar de publicar).

Esta é a versão estática (sem backend) da WebApp — os dados que noutro
contexto seriam calculados em tempo real por um servidor (recorte por
região, séries temporais) foram pré-calculados e estão em `data/`. O
código-fonte completo e o processo de desenvolvimento mantêm-se num
repositório privado; ver
[ondas_calor_frio_showcase](https://github.com/drodrigues704-coder/ondas_calor_frio_showcase)
para uma apresentação do projeto.
